## Failure modes and checks

| Failure | Useful check |
|---|---|
| Missing context | Include constraints and input locations |
| Incomplete findings | Verify evidence and requested coverage |
| Conflicting edits | Assign file ownership before work starts |
| Unbounded work | Limit scope and monitor usage |
| Coordination stalls | Check dependencies and name an integrator |

Separate contexts can still share files and assumptions. Agreement alone does not establish correctness.
